# Image Slideshow plugin

Edit `config.json`, place 458 × 196 PNG/JPG/SVG files in `slides/`, and restart Ulanzi Studio. The minimum interval is 5 seconds. The plugin is offline and only renders contexts assigned to key `3_2`.

The normal **Setup Large Display** action provides Install, Repair, and Restore operations. Press the assigned key while Studio is open, then close Studio only when it displays **CLOSE STUDIO**; the detached assistant applies the verified operation and restarts Studio.

Full install, safety, and recovery instructions are in the top-level `README.md` delivered with this package.
