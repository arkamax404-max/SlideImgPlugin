ImageSlidePlugin 0.7.4 universal release verification
================================================================

Scope
-----
- One source tree and one plugin ZIP for Windows x64, macOS x64, and macOS arm64.
- Stable plugin/action UUIDs and preserved Windows helper files/behavior.
- macOS Setup is ProfilesV2-only and requires manual Studio reopen.
- Configurable localized date/time screen between images or as an exclusive clock-only display.
- Setup diagnostics and Windows Restore lineage remain bound across new pages and repeated cycles.
- Optional WeatherAPI current conditions and three-day forecast with bundled MIT Meteocons.
- Independent content controls, two-panel clock, CPU/GPU/RAM screen, and ordered due-panel queue.
- CPU/GPU/RAM sampling runs only while the system-resource panel is visible.
- The active Windows plugin was backed up and updated for physical validation; packaging did not modify the live profile or D200 state.

   - Rollback boundary: weather module/assets, slideshow/Inspector integration, docs, and tests.

4. Localized date/time display

Physical validation status and limitations
------------------------------------------
- macOS x64 slideshow import/decode and ProfilesV2 Setup/Restore have prior physical evidence.
- That prior local Studio evidence used an installed disposable manifest with `macos`; it was not
  modified. Source and release artifacts now use the official `mac` schema token.
- macOS clock overlay can remain visible; this is an accepted release-candidate limitation.
- macOS requires manual Studio reopen after Setup; relaunch is not implemented.
- Windows x64 installation, manual profile import, action discovery, slideshow rotation, and clock suppression passed on a physical D200.
- Periodic date/time insertion, localized/system and explicit date formats, bold clock typography,
  and continuous date/time-only mode were accepted on the physical Windows D200.
- Periodic/weather-only modes, flat PNG Meteocons, three-day forecast cards, and final typography
  were accepted on the physical Windows D200.
- Independent content controls, two-panel Lucide clock, live CPU/GPU/RAM cards, information-only
  rotation, and date/weather/system due-panel sequencing were accepted on the physical Windows D200.
- Windows Setup accepted a physical Restore -> Install -> Restore cycle after Studio normalization.
- Windows automated verification passed 59/59 Node tests and 30/30 available Python tests; 2
  production-shape profile tests remain skipped because their optional external fixture was absent.
- macOS arm64 packages were statically validated only; Apple Silicon was not physically tested.
- Authoritative `resources/store` artwork is enforced as 2:1 cover and 3:2 banner with rounding tolerance and minimum 1200 px width.
- Publication and upload occur only after this report, the clean artifacts, and their checksums pass.
