# Setup Large Display — parity with Media Control for D200

Goal: make the **Setup Large Display** key in `com.arkamax.ulanzi.imageslide.ulanziPlugin`
reuse the icon and the Property Inspector zone of MediaControlGsmtcPlugin's
`com.arkamax404.ulanzi.mediacontrol.setup-large-display` action, and harden the
Windows Studio executable discovery, without losing macOS compatibility.

## Reference (MediaControlGsmtcPlugin)

- Icon: `com.arkamax404.mediacontrold200.ulanziPlugin/assets/setup-large-display.svg`
- Property Inspector: `property-inspector/setup/inspector.html` + `inspector.js`
- Recent Windows path fix (uncommitted): `runtime/python/profile_assistant.py`
  probes `UlanziDeck`, `Ulanzi Deck`, `Ulanzi Studio` under `%ProgramFiles%`.

## Locked decisions

1. Property Inspector: full visual redesign in the MediaControl style.
2. Asset icon: exact MediaControl glyph and palette.
3. Assigned-key icon: embed the MediaControl art in the SVG generated by `plugin/setup.js`,
   preserving the state label. `setBaseDataIcon` stays; `setPathIcon` is NOT ported.
4. Windows Studio path discovery is in scope for this work.

## Invariants that must not regress

- macOS: `Invoke-ImageSlideSetup.mjs` relaunch stays manual (`MANUAL_REOPEN`), and the
  Property Inspector hint keeps the "reopen Studio manually" instruction.
- The Property Inspector keeps the raw WebSocket transport. No `vendor/ulanzi-sdk`,
  no `$UD`.
- The bounded `[CODE:PHASE]` diagnostic stays visible in the Property Inspector.
- `property-inspector/setup.html` keeps its path (pinned by `test/setup.test.js` and
  `tests/test_delivery.py`).
- `body { background: transparent }` in the Property Inspector is preserved so the
  Studio theme is inherited instead of overridden.
- `helper/compatibility.json` keeps the `studio.fileVersion` and `studio.sha256` keys
  and the `state.profileStores` value (`tests/test_delivery.py:97`,
  `test/macos-setup.test.js`).

## Fixed on 2026-09-16

- `tests/test_delivery.py`: four `read_text()` calls now pass `encoding="utf-8"`
  explicitly. The root cause was `Path.read_text()` falling back to the Windows locale
  (cp1252), so the UTF-8 `Pérez` in `manifest.json` decoded as mojibake. JSON is UTF-8
  by definition, so the read was the bug, not the manifest.
- `resources/store/cover.jpg`: regenerated at 1200x630 from `assets/cover.png`. The
  working tree had replaced the committed 1200x630 cover with a 1200x600 one. The fix
  scales to 1260x630 and centre-crops to 1200x630, which reaches the official ratio
  without adding bands and stays inside the documented crop-safe margins. Verified by
  eye: nothing essential is trimmed.

Note: `assets/cover.png` remains 1200x600. It is the design source and is not shipped,
but any regeneration script that derives the JPEG from it must crop to 1200x630.
